## WiFi enabled Air Quality Monitor PC Based App.  
Tested on Windows 7, 10 & 11  
Python 3.12+  
PyQt5 or 6  

Note: The file: 'main_window.ui' is the QT6 Designer file - it is included in case anyone wants to make changes or additions. This file should be compiled with the 'pyuic6' compiler to a file named: 'ui_main_window.py'. Also be sure to include the PyQt5 imports at the top of the compiled python file if PyQt5 compatibility is required.
