## Air Quality Monitor Circuit Python Code.  
Based on the Adafruit Air Quality Monitor and Case hardware design,    
https://learn.adafruit.com/aqi-case/overview   

You need these files to run the monitor,  
CIRCUITPY:  
├── lib  
│ ├── adafruit_bus_device   
│ ├── adafruit_display_text  
│ ├── adafruit_displayio_layout  
│ ├── adafruit_pm25  
│ ├── adafruit_register  
│ ├── adafruit_connection_manager.mpy  
│ ├── adafruit_max1704x.mpy  
│ ├── adafruit_requests.mpy  
│ ├── adafruit_scd4x.mpy  
│ ├── adafruit_ticks.mpy  
│ └── neopixel.mpy  
├── boot_out.txt <- Included with the device  
├── code.py  
├── conversions.py  
├── display.py  
├── leds.py  
├── sensors.py  
└── settings.toml <- Included with the device, but some changes needed
